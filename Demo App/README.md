# Fernwick Library Printing

An interactive React demo of a library printing service. Patrons submit a PDF, collect their print at a kiosk, and ask staff to check the job status.

## Try the demo

To make the demo easy to try, I bundled the React app and its assets into a single HTML file. Just download [index.html](index.html) and double-click it to open it in your browser. The demo works offline without npm or a local server.

1. Select **Print Kiosk** and enter the sample release code `AAABBBCC`.
2. Select **Find my print job**, then follow the prompts to simulate payment and printing.
3. Select **Library Staff** and search release code `AAABBBCC to see the updated status.

To try the patron flow, select **Patron**, choose a pickup library, and select a PDF to generate a new release code.
